# 俄罗斯方块硬件综合开发

> **重庆邮电大学** — 硬件综合开发课程设计

基于 FPGA 的俄罗斯方块游戏硬件开发项目，包含 VGA 显示、红外遥控控制等功能模块。

## 项目结构

```
├── main.c                  # 主程序入口
├── tetris.c                # 俄罗斯方块核心逻辑
├── game_UI.c               # 游戏界面显示
├── score.c                 # 分数管理模块
├── infrared_control.c      # 红外遥控控制
├── global_variable.h       # 全局变量定义
├── Makefile                # 项目构建文件
├── 代码分析与核心逻辑说明.txt    # 代码分析文档
└── 硬件综合开发报告模板.docx     # 开发报告
```

## 功能特性

- 俄罗斯方块核心游戏逻辑（移动、旋转、消行）
- VGA 游戏界面显示
- 红外遥控器操作控制
- 分数统计与显示
